# Experiment 07 – Unification and Resolution

**Aim:** Demonstrate unification of predicates and a simple resolution-style proof using a knowledge base.

**Run:** `python main.py`

**Sample output:**
```text
Unification: {'x': 'John'}
Query is resolved: John is Mortal
```

This is a small teaching example for the Human(John) → Mortal(John) rule in the lab manual.
