# Experiment 05 – Minimum and Maximum of Two Numbers (Prolog)

**Aim:** Find the minimum and maximum of two numbers using Prolog predicates.

**Run in SWI-Prolog:** consult `min_max.pl`, then try:
```prolog
?- minimum(5, 10, Min).
?- maximum(5, 10, Max).
?- minimum(8, 3, Min), maximum(8, 3, Max).
```
