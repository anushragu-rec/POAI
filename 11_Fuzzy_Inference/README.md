# Experiment 11 – Fuzzy Inference System

**Aim:** Estimate employee performance from work experience and project success rate using fuzzy logic.

**Install:** `python -m pip install -r ../requirements.txt` (run from the repository root), or install `numpy` and `scikit-fuzzy`.

**Run:** `python main.py`

**Inputs:** Experience = 12 years; Success rate = 70%.
